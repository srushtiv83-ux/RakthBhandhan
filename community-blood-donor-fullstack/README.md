# Community Blood Donor & Emergency Volunteer Network

Full-stack starter project for the CBP.

## Stack
Frontend: React + Vite + CSS
Backend: Node.js + Express
Database: MongoDB + Mongoose
Authentication: JWT + bcrypt
API: REST

## Run

### Backend
cd backend
npm install
copy .env.example .env
npm run dev

### Frontend
cd frontend
npm install
npm run dev

The backend uses MongoDB. Set MONGODB_URI and JWT_SECRET in backend/.env.
